Поля дат редко принимают фиксированное значение: дата начала должна быть на месяц в будущем, форма ждёт завтрашнюю дату, отчёту нужен первый день следующего месяца. Статическая дата в TestSheet (тестовом листе) работает в день написания и ломается назавтра. Выражения дат Tosca вычисляют значение в момент прогона от текущей (или любой базовой) даты, применяют смещение и печатают результат в формате, который ждёт приложение, без кода на Java или .NET.

## Простые выражения даты и времени

После ввода `{` в TestStepValue (значении тестового шага) Tosca показывает список всех выражений; относящиеся к датам приведены ниже. Примеры вывода взяты из тестового случая, который записывает каждое выражение в `TBox Set Buffer` и читает результаты в логе ScratchBook; прогон выполнен 14 августа 2023.

| Выражение | Возвращает | Вывод в видео |
|---|---|---|
| `{DATE}` | Полную текущую дату | `14.8.2023` (текущая дата прогона) |
| `{DATETIME}` | Текущие дату и время (метка времени) | дата плюс время |
| `{TIME}` | Только текущее время | |
| `{DAY}` | Текущий день, число | `14` |
| `{MONTH}` | Текущий месяц, число | `8` |
| `{YEAR}` | Текущий год, число | `2023` |
| `{MONTHFIRST}` | Первый день текущего месяца как полную дату | 1 августа 2023 |
| `{MONTHLAST}` | Последний день текущего месяца как полную дату | 31 августа 2023 |
| `{SYSTEMDATE}` | Полную дату в формате, заданном операционной системой | дата в системном формате |
| `{NDAY}`, `{NMONTH}`, `{NYEAR}` | День, месяц, год двумя цифрами с ведущим нулём (`8` становится `08`) | `08` для августа |
| `{ADAY}`, `{AMONTH}` | Трёхбуквенное сокращение дня недели или месяца | `Mon`, `Mar` |
| `{LDAY[выражение даты]}` | День недели для даты, словом, согласно системным настройкам | `Friday` |

Автор отмечает, что выражений больше, чем перечислено; в таблице только то, что показано в видео.

## Расчётные даты: DATE с базой, смещением и форматом

```
{DATE[базовая дата][смещение][формат]}
```

| Часть | Значение |
|---|---|
| базовая дата | Дата, от которой считать. Пусто — сегодня. Может быть литералом или буфером вроде `{B[fulldate]}`. |
| смещение | Отклонение от базовой даты: `+`/`-`, число и единица. Показанные единицы: `D` дни, `M` месяцы, `Y` годы. Можно сцеплять: `+1M+1D`, `+2M-1D`. Автор упоминает недели и «другие варианты», но не показывает их. |
| формат | Шаблон вывода из `dd` (день), `MM` (месяц, заглавными), `yyyy` (год), например `MM/dd/yyyy`. Пусто — остаётся формат по умолчанию (системный). |

:::caution
Все три пары скобок обязательны, даже пустые. `{DATE[][+1D][]}` корректно; выбрасывать пустые скобки нельзя.
:::

Собственное описание выражения в Tosca приводит пример: базовая дата 23 мая 2016, смещение `+3M-1D`, формат `MM/dd/yyyy`.

| Выражение | Результат |
|---|---|
| `{DATE[][+1M+1D][MM/dd/yyyy]}` | Месяц и день от сегодня, формат США: `11/17/2023` при прогоне 16 октября 2023 |
| `{DATE[][+1D][]}` | Завтра в формате по умолчанию |
| `{DATE[][+1D][dd<sep>MM<sep>yyyy]}` | Завтра как день-месяц-год (этого требует препятствие из урока 123) |
| `{DATE[{B[fulldate]}][+2M-1D][yyyy<sep>MM<sep>dd]}` | Два месяца вперёд и день назад от буферизованной даты: 14.8.2023 становится 13 октября 2023 |
| `{MONTHFIRST[{B[generatedDate]}][+2M][yyyy-MM-dd]}` | Первый день второго следующего месяца, формат ISO |
| `{LDAY[{DATE[25<sep>12<sep>2024][+2Y][]}]}` | День недели 25 декабря 2026: `Friday` |
| `{DATE[{B[todaydate]}][][dd<sep>MM<sep>yyyy]}` | Переформатировать буферизованную дату без смещения |

:::note
`<sep>` обозначает разделитель, который автор вводит, но субтитры не фиксируют (`.`, `/` или `-`). Там, где разделитель произнесён вслух (`MM/dd/yyyy` в уроке 36), он приведён буквально. `MONTHFIRST` принимает те же аргументы база/смещение/формат, что и `DATE`.
:::

Щёлкните правой кнопкой по значению и выберите **Translate value**, чтобы увидеть вычисленную дату до запуска; в видео это делается для каждого выражения.

## Примеры

### Дата на месяц в будущем

Экран *Enter product data* демо-приложения Tricentis Vehicle отвергает дату начала, если она не более чем на месяц в будущем, и ждёт `MM/dd/yyyy`. Ровно месяц отвергается, поэтому смещение — месяц плюс день: `{DATE[][+1M+1D][MM/dd/yyyy]}`. Каждый день прогон создаёт новую допустимую дату, и тест не устаревает.

### Завтрашняя дата (препятствия 17 и «get tomorrow's date»)

Отсканируйте единственное текстовое поле, перетащите Module (модуль) и задайте `{DATE[][+1D][]}`, если формат по умолчанию уже подходит, либо `{DATE[][+1D][dd<sep>MM<sep>yyyy]}`, когда поле требует день-месяц-год. Translate value подтверждает завтрашнюю дату. Если страница не реагирует на введённый текст (препятствие из урока 123 не засчитало ввод), вводите через `{SENDKEYS[...]}`, как описано в разделе [Случайные значения](/ToscaBase/ru/expressions/random-values/).

### Первый день второго следующего месяца (препятствие 14, «confusing dates»)

Кнопка календаря генерирует дату в формате США; ответом должно быть первое число второго следующего месяца в формате ISO, затем нажимается **Done**.

1. Отсканируйте кнопку календаря, поле сгенерированной даты, поле решения и кнопку Done.
2. Для обоих атрибутов дат щёлкните правой кнопкой в разделе свойств, выберите **Configuration Parameter** и добавьте системный параметр `TargetDateFormat` со значением — шаблоном США месяц/день/год. Имя должно быть написано в точности так, как его определяет Tosca.
3. Шаги: клик по кнопке; **Buffer** сгенерированной даты в `generatedDate` со сменой типа данных со String на **Date**; ввод `{MONTHFIRST[{B[generatedDate]}][+2M][yyyy-MM-dd]}` в поле решения; клик по Done.

:::note
В видео выражение при вводе незаметно превратилось в `MONTH`, и его пришлось исправить обратно на `MONTHFIRST`; проверяйте подсвеченное имя перед запуском.
:::

### День недели будущей даты (препятствие 29, «future Christmas»)

Поле ждёт день недели словом, на который выпадет 25 декабря через два года. Вложите `DATE` с литеральной базовой датой и смещением `+2Y` в `LDAY`: `{LDAY[{DATE[25<sep>12<sep>2024][+2Y][]}]}`. Translate value возвращает `Friday`, это значение и вводится в поле.

## Проблема формата даты Tosca

Tosca интерпретирует каждый литерал даты по одному формату: формату системы, где она установлена, или заданному внутри Tosca. Выражение `DATE` умеет конвертировать *из* этого формата, но литерал в любом другом формате вообще не распознаётся как дата, и шаг падает.

Пример: системный формат — день-месяц-год, `TBox Set Buffer` с именем `todaydate` содержит `2024<sep>03<sep>07` (год-месяц-день), а второй Set Buffer `newdate` использует `{DATE[{B[todaydate]}][][dd<sep>MM<sep>yyyy]}`. Выражение верное, но прогон падает: буферизованное значение не интерпретируется как дата.

Решение: в тестовой конфигурации тестового случая добавьте системный Test Configuration Parameter (параметр тестовой конфигурации) **ToscaDateFormat** и выберите из списка значений формат, соответствующий *исходному* значению. После этого Tosca считает такой формат допустимым, и конвертация проходит. См. [Параметры тестовой конфигурации](/ToscaBase/ru/data-and-parameters/test-configuration-parameters/).
