Значения, прочитанные из приложения, редко приходят в том виде, который нужен проверке: номер заказа встроен в подпись, цена содержит знак валюты, в тексте лишние пробелы. Строковые операции Tosca — динамические выражения, преобразующие строку на месте, обычно внутри шага `TBox Set Buffer`, чтобы очищенное значение можно было сохранить в Buffer (буфер) и использовать дальше. Они заменяют методы `String` из Java или .NET.

## Справочник

Все операции принимают входную строку первым аргументом; обычно это буфер (`{B[имя]}`) или Test Configuration Parameter (параметр тестовой конфигурации, TCP) `{CP[имя]}`. Выражения свободно вкладываются друг в друга.

| Выражение | Результат | Пример из видео |
|---|---|---|
| `{STRINGLENGTH[строка]}` | Число символов | `{STRINGLENGTH[{B[str]}]}` вернул `15` для образца `Tricentis Tosca` |
| `{STRINGTOUPPER[строка]}` | Строчные буквы переведены в верхний регистр | `{STRINGTOUPPER[{B[str]}]}` |
| `{STRINGTOLOWER[строка]}` | Заглавные буквы переведены в нижний регистр | `{STRINGTOLOWER[{B[str]}]}` |
| `{NUMBEROFOCCURRENCES[строка][шаблон]}` | Сколько раз встречается шаблон (один или несколько символов), с учётом регистра | `{NUMBEROFOCCURRENCES[{B[str]}][t]}` вернул `1` |
| `{NUMBEROFOCCURRENCES[строка][шаблон][IGNORECASE]}` | То же без учёта регистра | `{NUMBEROFOCCURRENCES[{B[str]}][t][IGNORECASE]}` вернул `3` |
| `{TRIM[строка]}` | Убирает пробелы в начале и конце | `{TRIM[{B[B_order]}]}` |
| `{STRINGREPLACE[строка][шаблон][замена]}` | Заменяет каждое вхождение шаблона | `{STRINGREPLACE[{B[price1]}]["\$"][]}` |
| `{STRINGREPLACE[строка][шаблон][замена][IGNORECASE]}` | То же без учёта регистра | `{STRINGREPLACE[{B[B_order]}][Order number:][][IGNORECASE]}` |
| `{BASE64[текст][ENCODE]}` | Кодирует текст в Base64 | `{BASE64[{CP[username]}][ENCODE]}` |
| `{BASE64[закодированный текст][DECODE]}` | Декодирует строку Base64 | `{BASE64[{B[encode_username]}][DECODE]}` |
| `{MATH[выражение]}` | Вычисляет арифметическое выражение | `{MATH[{B[price1]}+{B[price2]}]}` |

:::note
В видео урока 148 арифметическое выражение называется `CALC`; в этой базе знаний везде используется `MATH` (см. [Случайные значения](/ToscaBase/ru/expressions/random-values/)). Правильно составленное выражение подсвечивается в ячейке; если оно остаётся обычным текстом — ошибка в скобках.
:::

## Экранирование специальных символов в шаблонах

`{STRINGREPLACE[{B[price1]}][$][]}` ничего не делает: **Translate value** показывает, что знак доллара остался. Символы со специальным значением нужно экранировать обратной косой чертой, а шаблон заключить в двойные кавычки: `{STRINGREPLACE[{B[price1]}]["\$"][]}`. После этого перевод показывает чистое число.

## Примеры

### Извлечь номер заказа из подписи подтверждения

Оформление заказа в интернет-магазине заканчивается строкой вроде *Order number: 1431918*, и номер меняется при каждом заказе. Цель: сохранить в буфер только число для последующей проверки.

1. В Module (модуле) идентифицируйте подпись по `InnerText` с подстановочным символом, `Order number*`, чтобы ModuleAttribute (атрибут модуля) совпадал с любым номером.
2. Шаг 1: ActionMode **Buffer**, буферизация `InnerText` в `B_order`. Лог показывает, что в буфере вся подпись со словами *Order number:* и множеством пробелов до и после.
3. Шаг 2 (`TBox Set Buffer`, буфер `B_order_number`): заменить префикс на пустоту, затем обрезать остаток:

   ```
   {TRIM[{STRINGREPLACE[{B[B_order]}][Order number:][][IGNORECASE]}]}
   ```

   `IGNORECASE` необязателен; он защищает от разного регистра подписи в приложении.
4. Лог сообщает: *buffer with name B_order_number has been set to value 1431918*.

Автор вставляет это выражение, а не набирает: вложенные фигурные и квадратные скобки легко перепутать, а одна пропущенная скобка делает всё значение недействительным.

### Сложить цены со знаком валюты

Два товара в корзине показывают цены с `$`; тест должен проверить их сумму.

1. Отсканируйте оба элемента с ценами (увеличивайте число отфильтрованных элементов в диалоге сканирования, пока они не появятся), переименуйте их в `item1`, `item2`, сохраните Module как `cart`.
2. **Buffer** `InnerText` каждого в `price1` и `price2`.
3. `{MATH[{B[price1]}+{B[price2]}]}` в Set Buffer с именем `sum` падает: из-за `$` это *not a valid expression*.
4. Замените буферы очищенными версиями через `{STRINGREPLACE[{B[price1]}]["\$"][]}` (и так же для `price2`), затем повторите выражение `MATH`. Прогон проходит, лог показывает сумму (`39.98` в видео); её можно сверить со страницей шагом **Verify**.

### Кодирование и декодирование учётных данных через Base64

Логины, пароли или реквизиты базы данных, хранящиеся в Test Configuration Parameters, можно замаскировать Base64, чтобы открытый текст не гулял по набору тестов.

| Имя Set Buffer | Значение |
|---|---|
| `encode_username` | `{BASE64[{CP[username]}][ENCODE]}` |
| `encode_password` | `{BASE64[{CP[password]}][ENCODE]}` |
| `decode_username` | `{BASE64[{B[encode_username]}][DECODE]}` |
| `decode_password` | `{BASE64[{B[encode_password]}][DECODE]}` |

После первых двух шагов лог показывает закодированные строки, после последних двух — исходные значения. Передача обычного текста вместо закодированного буфера в `DECODE` завершается ошибкой, что автор случайно демонстрирует.

:::tip
Кодирование и декодирование одного значения в одном тесте — только демонстрация. На практике вы получаете уже закодированное значение (буфер или параметр) и делаете `DECODE` там, где тесту нужен открытый текст, либо `ENCODE` того, что вернуло приложение (ID заказа, данные клиента), перед сохранением.
:::

## Где применяются строковые операции

Используйте их всякий раз, когда буферизованное значение нужно сравнить с ожидаемым результатом, подать в расчёт или ввести в другое поле в ином виде. Сама буферизация описана в разделе [Буферы](/ToscaBase/ru/data-and-parameters/buffers/), Module `TBox Set Buffer` — в [Операциях с буферами](/ToscaBase/ru/standard-modules/buffer-operations/); разбиение строки на несколько буферов регулярными выражениями — в разделе [Интервалы и выражения проверки](/ToscaBase/ru/expressions/intervals-and-verification-expressions/).
