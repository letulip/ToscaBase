Этот раздел замыкает цикл между бизнес-требованиями и результатами тестов. Он описывает раздел Requirements как дашборд, взвешенный по риску, язык запросов для отбора объектов к анализу, варианты отчётности, превращающие результаты в документы, и быстрый способ импортировать структуру папок из Excel.

Читайте в таком порядке:

1. [Требования и взвешивание по риску](/ToscaBase/ru/requirements-and-reporting/requirements-and-risk/): структура из папок, requirement set и требований; вес напрямую или через frequency class и damage class; привязка TestCase и ExecutionList для получения покрытия и состояния выполнения.
2. [Поиск TQL и виртуальные папки](/ToscaBase/ru/requirements-and-reporting/tql-and-virtual-folders/): операторы и структура Tosca Query Language и виртуальные папки, хранящие запрос как переиспользуемое представление.
3. [Отчёты и определения отчётов](/ToscaBase/ru/requirements-and-reporting/reports/): Print View, стандартные определения отчётов для ExecutionList, TestCase и требований и создание собственного определения отчёта с набором данных, TQL-запросом и дизайнером.
4. [Импорт структуры папок из Excel](/ToscaBase/ru/requirements-and-reporting/import-from-excel/): вставка иерархического листа в Commander через Create Folder Structure.
