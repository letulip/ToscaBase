Tosca управляет веб-страницами через **XBrowser engine (движок XBrowser)**, а XScan превращает страницу в **XBrowser Module** — репозиторий объектов с контролами приложения и их локаторами. Движок работает только с браузером, в котором установлено **Tosca Automation Extension (расширение автоматизации Tosca)**, поэтому расширение — предпосылка для любого сканирования и запуска в вебе. Страница описывает ручную установку в Chrome и Edge (Tosca может и сама предложить установку при первом сканировании, см. [Установку](/ToscaBase/ru/getting-started/installation/#расширение-браузера-для-xscan)) и знакомит с **тестируемой системой (system under test)**, которую уроки по Tosca 16 автоматизируют начиная с [Первого TestCase](/ToscaBase/ru/getting-started/first-test-case/).

## Какие браузеры

Tricentis публикует расширение для **Chrome**, **Firefox** и **Edge**. Страница расширения на сайте Tricentis ссылается на запись в магазине для каждого браузера; в уроке используется запись с пометкой «Tosca 13.2 и выше» — именно она подходит для Tosca 16.

## Установка в Chrome

1. Откройте страницу расширения Tricentis, выберите **Google Chrome** и перейдите по ссылке для Tosca 13.2 и выше; откроется Chrome Web Store. Либо найдите в Web Store *Tosca automation extension*.
2. Нажмите **Add to Chrome**, затем **Add extension** в диалоге подтверждения.
3. Значок расширения появляется в списке расширений Chrome. Больше ничего настраивать не нужно.

Если расширение уже установлено и вы хотите поставить его заново, сначала удалите его из Chrome — на странице магазина снова появится **Add to Chrome**.

## Установка в Edge

1. Откройте **Edge Add-ons** в Edge и найдите *Tosca automation extension*.
2. В результате **Tosca Automation Extension for Microsoft Edge** нажмите **Get**, затем **Add extension**.
3. Расширение появляется в списке расширений Edge.

:::note
Без расширения в сканируемом браузере XScan не может создавать XBrowser Module, а существующий TestCase не может управлять страницей. Установите его в каждый браузер, который собираетесь указывать значением Test Configuration Parameter `Browser`.
:::

## Тестируемая система: демо-магазин Tricentis

**Тестируемая система** — приложение, которое вы тестируете или автоматизируете. В уроках это **demo web shop** Tricentis — публичный интернет-магазин, созданный для обучения. Зарегистрироваться может любой, и стоит сделать это заранее, чтобы шаги входа в следующих уроках работали с вашей учётной записью.

- **Регистрация**: пол, имя, фамилия, email, пароль и его подтверждение.
- **Log in / Log out** из верхнего меню.
- **Категории товаров** (books, computers, electronics, apparel and shoes и другие): откройте категорию, выберите товар, например *Blue Jeans*, задайте количество и нажмите **Add to cart**; сообщение подтверждает, что товар в корзине.
- **Корзина**: примените купон на скидку или код подарочной карты, отметьте *agree to the terms of service* и нажмите **Checkout**.
- **Оформление заказа** проходит через платёжный адрес (новый или существующий), адрес доставки (совпадает с платёжным или самовывоз), способ доставки (ground, next day, second day — с разной ценой), способ оплаты (наложенный платёж, чек или денежный перевод, кредитная карта, purchase order) и платёжные данные, затем страницу подтверждения, где повторяются адреса, способы доставки и оплаты, цены, количество, налог и итог. **Confirm** размещает заказ и возвращает его номер.

Именно этот поток уроки автоматизируют шаг за шагом: вход, переход в категорию, заказ товара, оформление, проверка цен и страницы успеха, выход. Каждая страница становится Module (страница входа, верхнее меню, вкладка выбора товара, корзина, платёжный адрес, способ доставки, способ оплаты и т. д.), а TestCase связывает Module в цепочку.
