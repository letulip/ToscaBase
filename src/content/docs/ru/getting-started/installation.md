Tosca работает только под Windows. Установка — это загрузка около 1,5 ГБ (размер зависит от версии установщика; пробный установщик Tosca 15 LTS из [Лицензирования](/ToscaBase/ru/getting-started/licensing/) занимает около 1,4 ГБ), мастер, в котором подходят значения по умолчанию, подключение лицензии и одно расширение браузера, чтобы XScan видел веб-страницы. Если ваша машина не под Windows или слишком слабая, те же шаги работают на виртуальном Windows Server в AWS — это к тому же единственный способ управлять Tosca с Mac. Учётная запись поддержки и запрос лицензии — предпосылки; см. [Лицензирование](/ToscaBase/ru/getting-started/licensing/).

## Загрузка

- **Через портал поддержки**: войдите, откройте страницу запроса лицензии (где учебная лицензия показана как Deployed) и перейдите по ссылке загрузки либо откройте вкладку **Downloads**. В списке много продуктов Tricentis; выберите тот, у которого продукт — Tosca, а название — **Tricentis Tosca 16.0 LTS** (версия 16.0). Не путайте с другими продуктами, связанными с 16.0. В уроке по Tosca 16 тот же файл находят на странице загрузок портала, выбирая **Tricentis Tosca**, а затем пункт **Tosca 16**; урок датирует выход 16.0 началом декабря 2022 года.
- **Через бесплатный trial**: страница подтверждения запроса trial предлагает установщик напрямую (на момент записи — Tosca 15 LTS).

Время загрузки зависит от соединения; файл — zip-архив. Распакуйте его: в папке лежат приложение-установщик и файл контрольной суммы `sha256`. Двойной щелчок по приложению запускает мастер.

## Мастер установки

1. **Welcome**: отметьте *I agree to license terms* и нажмите **Continue**.
2. **Prerequisites**: недостающие компоненты устанавливаются автоматически. **Next**.
3. **Setup type**: оставьте **Tosca Commander**. Другие варианты — настроить машину как *execution agent* (см. [Распределённое выполнение](/ToscaBase/ru/execution/distributed-execution-dex/)) или *custom*-установка.
4. **Paths**: папки установки по умолчанию можно изменить; оставьте их.
5. **Tosca Diagnostics**: статистика использования. Снимите флажок, если не хотите её отправлять.
6. **Update service**: включить или пропустить.
7. **Tosca Data Integrity**: для UI-автоматизации не нужен; не устанавливайте.
8. **Vision AI engine**: оставьте по умолчанию — он будет установлен.
9. **Review**: список устанавливаемых компонентов; отдельные компоненты здесь ещё можно убрать. Нажмите **Install**.
10. Установка занимает пару минут. Каждый компонент отмечается зелёной галочкой; при сбое доступны логи. Нажмите **Finish**.

Если уже установлена более старая Tosca (например, 14.3), установщик предложит **обновление** до загруженной версии вместо чистой установки. Если та же версия уже стоит, он предложит **Uninstall**, **Repair** или **Modify**.

После установки в меню «Пуск» Windows появляется папка **Tricentis** со всеми установленными компонентами; нужен **Tosca Commander**. Диалог **About Tosca** в Commander показывает установленную версию — так в уроке по Tosca 16 убеждаются, что запущена 16.0. При первом запуске он запрашивает лицензию: подключите её, как описано в [Лицензировании](/ToscaBase/ru/getting-started/licensing/), после чего откроется стартовая страница, где создаётся workspace ([Workspace и настройка проекта](/ToscaBase/ru/getting-started/workspace-and-project-setup/)).

## Расширение браузера для XScan

Для сканирования веб-приложения в браузере нужно расширение Tosca. Без него запуск **Scan > Application** на окне Chrome показывает сообщение *browser extension not installed or outdated*.

1. Ответьте **Yes**. Tosca откроет страницу расширения в браузере.
2. Нажмите **Add to Chrome** и подтвердите.
3. Закройте страницу и запустите сканирование снова; теперь открывается окно XScan и можно добавлять контролы.

Как установить расширение вручную, добавить его в Edge или Firefox и познакомиться с демо-магазином, который автоматизируют уроки по Tosca 16, — в [Tosca Automation Extension](/ToscaBase/ru/getting-started/tosca-automation-extension/). О самом сканировании — [XScan](/ToscaBase/ru/modules/xscan/).

## Запуск Tosca на Windows Server в AWS EC2

Урок QASCRIPT разворачивает Tosca 16.0 на бесплатном (free-tier) аккаунте AWS. Шаги: создать Windows-инстанс EC2, подключиться по RDP, загрузить и установить Tosca, подключить лицензию, установить расширение браузера.

### Запуск инстанса

1. В консоли AWS откройте **EC2 > Instances > Launch instance** и задайте имя (например, `Tosca web server`).
2. **AMI**: выберите образ Windows. Базовый образ free-tier по умолчанию — **Windows Server 2022** — подходит.
3. **Instance type**: `t2.micro` из free-tier имеет 1 ГБ памяти — этого мало для чего-либо, кроме демонстрации. Для реальной работы выберите **`t2.large` (8 ГБ)** или больше; 8 ГБ — рекомендуемый минимум для Tosca.
4. **Key pair**: создайте пару (например, `Tosca server`) в формате **`.pem`**. Файл скачивается автоматически; он нужен для расшифровки пароля Windows.
5. **Network settings**: создайте группу безопасности, разрешающую **RDP** (при желании ограничьте источник до *My IP*), а также **HTTP** и **HTTPS**. Без них сервер недоступен.
6. **Storage**: 30 ГБ по умолчанию достаточно для Tosca Commander.
7. Оставьте расширенные настройки, один инстанс (второй нужен только если хотите развести Tosca Server и Commander по разным машинам) и нажмите **Launch instance**. Дождитесь состояния **Running**.

### Подключение по RDP

1. Выберите инстанс, нажмите **Connect** и перейдите на вкладку **RDP client**.
2. **Download remote desktop file**. Имя пользователя — `Administrator`.
3. Нажмите **Get password**, загрузите файл `.pem` и нажмите **Decrypt password**. Скопируйте пароль.
4. Откройте RDP-файл, вставьте пароль и подтвердите диалоги подключения. При первом входе ответьте **Yes** на запрос сетевого обнаружения.

### Установка Tosca на сервере

Откройте Edge (завершите его первичную настройку), войдите на портал поддержки Tricentis, откройте страницу запроса лицензии и загрузите Tosca 16.0 LTS, как описано выше. Распакуйте, запустите установщик с настройками по умолчанию, запустите **Tosca Commander** из меню «Пуск» и подключитесь к облачному серверу лицензий с учётными данными портала. Создайте однопользовательский workspace со стандартным шаблоном — Commander откроется.

На свежем Windows Server нет Chrome; установите его, затем при первом сканировании добавьте расширение Tosca, как описано выше.

:::tip
Инстанс побольше стоит денег, но позволяет работать с Tosca с Mac или любой другой ОС через RDP, держать его запущенным для долгих выполнений и не нагружать собственную машину. Саму Tosca на macOS установить нельзя.
:::
