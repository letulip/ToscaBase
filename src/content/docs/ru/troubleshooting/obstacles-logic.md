Последние два препятствия *Obstacle Course* (полосы препятствий) Tricentis нельзя записать ни прямым списком TestStep (шагов теста), ни через свойство папки [Repetition](/ToscaBase/ru/test-cases/repetitions/): число проходов неизвестно, и на каждом проходе нужно посмотреть на страницу и решить, что делать. Оба решаются оператором `Do` (сначала тело, затем условие), внутри которого стоит `If`; препятствие 33 добавляет ветку `Else` и ввод с клавиатуры через **TBox Send Keys**. Как устроены три объекта управления потоком, описано в [Управлении потоком](/ToscaBase/ru/test-cases/control-flow/); простейшее препятствие с циклом — *Again and again* (препятствие 15, `While`) — в [Препятствия: ввод и клики](/ToscaBase/ru/troubleshooting/obstacles-input-and-clicks/#снова-и-снова-again-and-again-препятствие-15). Tricentis по-прежнему не советует встраивать логику в TestCase; эти два случая — те, где без неё не обойтись.

## Сортировка пузырьком (Bubble sort, препятствие 32)

**Проблема.** Десять чисел в ряд и «пузырёк», выделяющий двух соседей. Если левое число больше правого, нажать *Swap*, затем *Next*; иначе только *Next*. Продолжать, пока числа не выстроятся по возрастанию — тогда подпись *Keep sorting* сменится сообщением об успехе.

**Причина.** Ни число проходов, ни действие в проходе неизвестны до запуска, а `InnerText` чисел меняется при каждом сдвиге пузырька.

**Решение.** Module (модуль):

1. Отсканируйте кнопки *Swap*, *Next* и *Keep sorting*; каждая уникальна по `id`.
2. Поднимите уровень **filtered items** дважды, пока не появится `div` пузырька. Снимите его `InnerText` (две текущие цифры), идентифицируйте по `class`, переименуйте в `bubble`.
3. Внутри пузырька два `div` с числами имеют одинаковые `class` `num` и `tag`. Снимите у обоих `InnerText` и переключитесь на *Identify by index*: индекс `1` — `first`, индекс `2` — `second`. Индекс здесь безопасен: в пузырьке всегда ровно два числа.

TestCase (тест-кейс):

1. Правой кнопкой — **Create Do Statement**. Tosca добавит части *Loop* и *Condition*.
2. Loop, первый шаг: **TBox Wait** на `500` мс, чтобы страница перерисовалась до того, как проход её прочитает.
3. Loop, второй шаг: `first` → свойство `InnerText`, ActionMode `Buffer`, значение `num1`.
4. Loop, третий шаг: правой кнопкой — **Create If Statement**.
   - Condition: `second` → свойство `InnerText`, ActionMode `Verify`, значение `<{B[num1]}`. Сначала задайте атрибуту тип данных *Numeric* в панели свойств: как строки, `9` больше `10`.
   - Then: *Swap* → `X`.
5. Loop, четвёртый шаг, после `If` и вне его: *Next* → `X`. Он выполняется на каждом проходе, потому что после обмена тоже нужно нажать *Next*.
6. Condition оператора `Do`: *Keep sorting* → свойство `InnerText`, ActionMode `Verify`, значение `Keep sorting`. Цикл повторяется, пока верификация проходит, и завершается, как только подпись меняется.

:::note
Оператор `Do` останавливается по свойству **Maximum repetitions**, по умолчанию 30. Десяти числам может понадобиться больше проходов; поднимите значение в свойствах оператора, как показано в препятствии 33.
:::

## Олимпиада Tosca (Tosca Olympics, препятствие 33)

**Проблема.** После *Start* лыжник едет по склону. Перед каждым деревом инструкция (*Go left* или *Go right*) говорит, какую стрелку нажать; текст заканчивается сообщением об успехе или о столкновении, если клавиша пропущена.

**Причина.** Число поворотов и направление каждого известны только во время выполнения, а кликать не по чему: ввод — это клавиша, отправленная окну браузера.

**Решение.** Module: кнопка *Start* и `div` инструкции (уровень фильтра поднят дважды; оставьте `id` и `tag`, снимите меняющийся `InnerText`; переименуйте в `instruction`).

TestCase:

1. *Start* → `X`.
2. Правой кнопкой — **Create Do Statement**; в его *Loop* — **Create If Statement**:
   - Condition: `instruction` → свойство `InnerText`, ActionMode `Verify`, значение `Go left`.
   - Then: стандартный Module **TBox Send Keys** с `Caption` = заголовок окна с подстановочным знаком (`Tricentis Obst*`) и `Keys` = `"{LEFT}"`.
   - Правой кнопкой по `If` — **Create Else Statement**; Else: ещё один **TBox Send Keys** с `"{RIGHT}"`. Вторая верификация не нужна: всё, что не *Go left*, — это *Go right*.
3. Condition оператора `Do`: `instruction` → `InnerText`, ActionMode `Verify`, *не равно* `{REGEX["crash|you did it"]}`. Цикл продолжается, пока не показано ни одно из финальных сообщений.
4. Откройте свойства оператора `Do` и поднимите **Maximum repetitions** с `30` до `100`. Первый запуск разбился ровно после 30 поворотов; игре понадобилось 44.

`TBox Send Keys` — тот же Module, что переключает вкладки браузера в [Типичных проблемах и решениях](/ToscaBase/ru/troubleshooting/common-problems-and-fixes/); всё, что пользователь может сделать с клавиатуры, может и он.

:::note
Автор читает условие цикла вслух как *not equal to*, не показывая оператор; отрицание в Tosca — `!=` перед значением, так что ячейка должна выглядеть как `!={REGEX["crash|you did it"]}`. Точный текст финальных сообщений тоже не показан; скопируйте его со страницы.
:::
