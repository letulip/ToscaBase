**Repetition** (повторение) — число на папке TestStep, заставляющее Tosca выполнить каждый TestStep внутри этой папки столько раз подряд. Это простейший способ повторить шаги: без условия, без буфера-счётчика, без объекта цикла. Типичные применения — сценарий, в котором действие действительно повторяется (добавить один товар в корзину пять раз), грубая проверка нагрузки на один элемент или, с буфером в качестве счётчика, один проход на каждую строку таблицы. Там, где достаточно счёта, Tricentis предпочитает это циклу `While`; см. [Структура TestCase](/ToscaBase/ru/best-practices/test-case-structure/).

## Где можно задать Repetition

Только на **папке** внутри TestCase. Свойство недоступно на отдельном TestStep и на самом TestCase. Чтобы повторить один шаг, положите его в отдельную папку.

Пример TestCase состоит из трёх частей: шаги логина, папка `Add products` с одним TestStep, кликающим `Add to cart`, и шаг закрытия приложения. Repetition ставится на `Add products`.

## Способ 1: колонка Repetition

1. В секции TestCases щёлкните правой кнопкой по строке заголовков колонок и выберите **Column Chooser**.
2. Найдите колонку **Repetition** и перетащите её в строку заголовков или дважды щёлкните по ней. Колонка появится для всех TestCase.
3. В строке папки введите число повторений, например `5`.

Чтобы убрать колонку, перетащите её заголовок из строки заголовков, пока не появится крестик, и отпустите.

## Способ 2: свойства папки

1. Выделите папку и откройте панель **Properties**.
2. Задайте свойство **Repetition**, например `4`.

Оба способа задают одно и то же свойство; изменение в панели свойств обновляет колонку и наоборот.

## Что вы увидите

- **Значок папки.** Как только Repetition задано, папка показывает закруглённую стрелку назад. Уберите Repetition — значок вернётся к обычной папке. Это самый быстрый способ заметить повторяемые шаги в большом TestCase.
- **Результаты.** В результате ScratchBook или ExecutionList узел папки перечисляет повторения; при раскрытии видно шаг, выполненный по разу на каждое повторение (пять записей для `5`, четыре для `4`).

## Счётчик, который приходит из приложения

Значением Repetition может быть буфер вместо литерала, а внутри папки выражение `{REPETITION}` возвращает номер текущего прохода (1, 2, 3, ...). Вместе они позволяют папке сделать что-то по разу на каждую строку таблицы без объекта цикла. Урок 24 так опустошает корзину; варианты того же сценария с `While` и `Do` — в [Управлении потоком](/ToscaBase/ru/test-cases/control-flow/).

1. `Verify table exists`: Module корзины, узел таблицы, `Exists == True`, ActionMode `Verify`.
2. `Count items in cart`: тот же Module, узел строк таблицы, свойство `ResultCount`, ActionMode `Buffer`, значение `CartItems`. Счётчик включает строку заголовка, так что он на единицу больше числа товаров.
3. `Calculate items without header`: **TBox Set Buffer**, буфер `ActualCartNumber`, значение `{MATH[{B[CartItems]}-1]}`.
4. Создайте папку `Select remove` и задайте её Repetition как `{B[ActualCartNumber]}`. Значок папки меняется, как только значение введено.
5. Внутри папки — один TestStep на Module корзины: строка `${REPETITION}`, колонка `Remove`, чекбокс `Input` `True`. На первом проходе селектор строки разворачивается в `$1`, на втором — в `$2`, и так далее, так что каждый проход отмечает следующую строку.
6. После папки один шаг кликает `Update shopping cart` (`X`).

С двумя товарами в корзине папка выполнилась дважды, оба чекбокса были отмечены, и единственный клик по обновлению опустошил корзину. Свойства таблицы вроде `ResultCount` и селекторы строк перечислены в [Табличных контролах](/ToscaBase/ru/modules/table-controls/); ещё одно применение `{REPETITION}` — адресация строки по ID на каждом проходе — в [Препятствиях: таблицы](/ToscaBase/ru/troubleshooting/obstacles-tables/).
