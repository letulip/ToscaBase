В стандартной поставке Tosca (Standard subset) есть набор готовых **TBox Automation Modules (модули автоматизации TBox)**. Это библиотека универсальных операций, которые можно добавить в любой TestCase без сканирования: работа с файлами и папками, буферами, процессами, таймерами и другое. Здесь описаны файловые и папочные Module. Добавляются они одинаково: в TestCase выбрать **Add TestStep**, найти `TBox` плюс название операции и заполнить ModuleAttributes (атрибуты модуля).

## Операции с файлами

### TBox Image Compare

Сравнивает два файла изображений.

| ModuleAttribute | Значение |
|---|---|
| First image file path | Путь к первому изображению (выбрать или вставить) |
| Second image file path | Путь ко второму изображению |

Шаг является проверкой: если изображения отличаются, верификация не проходит и TestCase падает. Именно это и ожидается при сравнении двух заведомо разных картинок.

### TBox Read/Create File

Один Module и читает, и создаёт текстовые файлы. Для создания файла:

| ModuleAttribute | Значение в примере |
|---|---|
| Directory | Целевая папка |
| File name | `test1.txt` |
| Text | Содержимое, которое нужно записать в файл |
| Encoding | `UTF-8` или `UTF-16` |
| Override | `True`, чтобы заменить существующий файл с тем же именем |
| Add byte order mark | `True` |

После запуска ScratchBook показывает Passed, а в папке появляется файл с указанным текстом.

### TBox Copy File

| ModuleAttribute | Значение |
|---|---|
| Source | Путь к копируемому файлу |
| Target directory | Папка назначения |
| Target file name | Имя копии, например `test2.txt` |
| Override | `True`, чтобы перезаписать существующий файл |

Работает с любым типом файлов (в видео упоминаются `.txt` и `.xml`), не только с текстовыми.

### TBox File Compare

Сравнивает содержимое двух файлов; частая проверка в TestCase.

| ModuleAttribute | Значение |
|---|---|
| First file path | Путь к файлу 1 |
| Second file path | Путь к файлу 2 |

- Файлы одинаковы: в log info сообщается, что содержимое идентично, **отчёт не создаётся**.
- Файлы различаются: верификация не проходит, TestCase падает, и Tosca создаёт **HTML-отчёт**. В отчёте красным выделено, что есть в одном файле и отсутствует в другом.

### TBox Delete File

Принимает один путь (например `...\test1.txt`) и удаляет файл.

### Другие файловые модули

В стандартном наборе есть также Module для чтения файла, перемещения, переименования и дописывания текста в конец. В исходном видео они не показаны; добавляются тем же способом через поиск.

## Операции с папками

### TBox Create Folder

| ModuleAttribute | Значение |
|---|---|
| Path | Полный путь создаваемой папки |
| Override | `True` |

:::caution
Указывайте путь **новой подпапки** (например `C:\Training\Folder1`), а не существующей папки. Если задать путь существующей папки с Override = `True`, Tosca перезапишет её вместо создания новой.
:::

### TBox Copy Folder

По запросу `TBox copy` находятся два Module, Copy File и Copy Folder; нужен второй.

| ModuleAttribute | Значение |
|---|---|
| Source path | Копируемая папка |
| Target path | Назначение; папка станет подпапкой |
| Override | `True` |

Копируется папка со всем содержимым (подпапки и файлы).

### TBox Delete Folder

| ModuleAttribute | Значение |
|---|---|
| Path | Удаляемая папка |
| Recursive | `True` удаляет папку вместе с содержимым; иначе содержимое не удаляется |

### TBox Folder Existence

Проверяет, что папка существует. Путь вводится вручную: у этого атрибута нет кнопки обзора. В результате показаны ожидаемое и фактическое значения (папка должна существовать / существует), и верификация проходит или нет.

:::tip
Типичное применение: проверить наличие папки отчётов или тестовых данных **до** запуска TestCase, которым она нужна. Сначала проверка существования, затем создание, копирование и удаление. Все шаги можно объединить в один TestCase и обернуть в условие `If`; см. [Управление потоком](/ToscaBase/ru/test-cases/control-flow/).
:::
