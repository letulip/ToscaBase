Скриншоты из прогона Tosca можно получить двумя способами. Module **TBox Take Screenshot** снимает экран в той точке TestCase, где вы его поставите. **Настройка проекта** делает скриншот автоматически при каждом падении TestStep, не затрагивая TestCase. Используйте их вместе: Module для скриншотов, которых требует задание, настройку для отладки сбоев.

Пример TestCase входит в демонстрационный интернет-магазин с заведомо неверными учётными данными и падает на верификации входа.

## TBox Take Screenshot

В **Add TestStep** найдите `TBox Take Screenshot`.

| ModuleAttribute | Значение |
|---|---|
| Environment | `Desktop` или `Mobile` |
| Directory | Папка для сохранения изображения |
| File name | Имя файла изображения |

После запуска в **Details** шага в ScratchBook показано, куда записан файл, а в log info сообщается, что скриншот создан.

### Уникальные имена файлов

Фиксированное имя вроде `Screenshot1` перезаписывается при каждом выполнении. Чтобы сохранять по снимку на прогон, добавьте к имени файла динамическое **выражение даты/времени** (см. [Выражения даты](/ToscaBase/ru/expressions/date-expressions/)). Имя тогда содержит дату и время с точностью до секунд и всегда уникально.

### Куда ставить шаг

Шаг скриншота, поставленный **после** падающего шага, не выполнится никогда, потому что TestCase останавливается на сбое. Ставьте его перед рискованным шагом (в примере: после нажатия Login, но до верификации входа). Шагов скриншота может быть сколько угодно в разных местах.

## Автоматические скриншоты при сбое TestStep

Настраивается один раз на проект в **Project settings > TBox > Logging > Screenshots**:

| Настройка | Рекомендуемое значение |
|---|---|
| Make screenshot on failed TestSteps | Включено (по умолчанию выключено) |
| При каком сбое | `Verification failure`. Второй вариант — сбой обнаружения (detection failure); тесты обычно падают на верификации, и именно там нужно видеть состояние |
| Screenshot directory | Любая папка, например та же, что у Module |
| Image format | `PNG` (предлагается несколько форматов) |

Настройка действует на все TestCase проекта.

### Просмотр скриншота

:::caution
ScratchBook не может показать автоматический скриншот. В его панели Details видна только запись `System.Drawing.Bitmap`. Чтобы увидеть изображение, запустите TestCase из **ExecutionList (списка выполнения)**.
:::

1. Перетащите TestCase в ExecutionList и выполните.
2. Откройте упавший TestStep в результатах. В разделе **Details** видны оба скриншота: снятый шагом TBox Take Screenshot и захваченный автоматически на упавшей верификации.
3. В примере на изображении видно сообщение магазина о неудачном входе, что и нужно для диагностики.

:::tip
Не переключайте окна и не закрывайте браузер, пока выполнение идёт: скриншот делается в момент сбоя и покажет то, что на экране. Смотрите результаты только после завершения выполнения.
:::
