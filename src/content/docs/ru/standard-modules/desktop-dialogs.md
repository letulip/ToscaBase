Диалог Windows **Save As** — это диалоговое окно рабочего стола, а не часть веб-страницы, поэтому HTML XEngine не может его отсканировать или управлять им. В стандартном наборе Tosca есть отдельный Module **TBox Save As**, который заполняет имя файла, выбирает кнопку и даже обрабатывает всплывающее окно подтверждения после сохранения. Он подходит для любого приложения со стандартным диалогом, например для документа Microsoft Office, который вы изменили и хотите сохранить под новым именем.

## TBox Save As

Добавляется через **Add TestStep** по запросу `TBox Save As`.

| ModuleAttribute | Значение | В примере |
|---|---|---|
| Caption | Заголовок окна диалога | `Save As` |
| File name label | Метка поля имени файла. Если это стандартное `File name`, Tosca управляет полем автоматически и атрибут можно оставить пустым; заполняйте только для нестандартной метки | `File name` |
| File path | Полный путь вместе с именем файла, который вводится в поле имени | `C:\Training\test.docx` |
| Button | Какую кнопку диалога нажать: `Save` или `Cancel` | `Save` |
| Confirmation popup caption | Заголовок всплывающего окна, которое может появиться после нажатия кнопки | `Microsoft Word` |
| Confirmation popup button | Кнопка в этом окне | `OK` |

## Пример: сохранить документ Word

1. Откройте документ, внесите изменение и откройте диалог Save As.
2. Добавьте **TBox Save As** с caption `Save As`, путём `C:\Training\test.docx`, кнопкой `Save`.
3. Запустите. Tosca вводит путь и нажимает Save, но Word показывает окно с сообщением, что документ будет преобразован в новый формат, и просит подтверждения. Пока окно не закрыто, файл **не** сохраняется.
4. Заполните **Confirmation popup caption** = `Microsoft Word` и **Confirmation popup button** = `OK`.
5. Верните приложение в исходное состояние (отмените попап, чтобы вернулся диалог) и запустите шаг снова. Файл сохраняется под заданным именем в заданной папке.

:::tip
Заранее не всегда известно, появится ли попап после нажатия Save. Запустите шаг один раз без двух атрибутов подтверждения, посмотрите, что появилось, и внесите заголовок и имя кнопки. Те же два атрибута обрабатывают вопрос о перезаписи существующего файла.
:::

:::note
В транскрипте имя файла звучит как «test dot doc», а затем «test dot talk»; точное расширение не слышно. Подойдёт любое расширение Word; суть в том, что путь и имя файла вводятся в один атрибут.
:::
