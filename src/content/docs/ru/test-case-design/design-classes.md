**Class (класс)** в разделе TestCase-Design — контейнер для атрибутов и экземпляров, нужных нескольким TestSheet. Вместо того чтобы создавать одни и те же атрибуты `Enter vehicle data` с одинаковыми экземплярами в листе `Automobile` и снова в листе `Truck`, вы создаёте их один раз в классе и помещаете в каждый лист **class reference (ссылку на класс)**. Изменения вносятся в класс и появляются во всех ссылках. Это аналог библиотеки TestStep ([Бизнес-параметры и библиотеки](/ToscaBase/ru/data-and-parameters/business-parameters-and-libraries/)) или функции, вызываемой из многих мест, только для TestCase-Design. Сами TestSheet и атрибуты описаны в [TestSheet и атрибуты](/ToscaBase/ru/test-case-design/test-sheets-and-attributes/).

## Когда класс окупается

В демо *Vehicle Insurance* разделы *Automobile*, *Truck*, *Motorcycle* и *Camper* начинаются с блока *Enter vehicle data*. Поля почти одинаковы; у *Truck* добавляются `Payload` и `Total weight`. Моделировать каждый тип транспорта отдельным TestSheet — значит дублировать атрибуты и их экземпляры, а каждое последующее изменение вносить четыре раза. Класс убирает дублирование и централизует сопровождение.

## Создание класса

Три способа, каждый заканчивается объектом класса (на иконке буква `C`) в папке TestCase-Design:

1. **Вручную.** Правой кнопкой по папке **> Create Class**, переименуйте и добавьте атрибуты и экземпляры точно так же, как в TestSheet.
2. **Из Module.** Перетащите Module (например, `Enter vehicle data`) в папку. Tosca создаст класс с именем Module, по атрибуту на каждый ModuleAttribute и экземпляры из значений контролов. Проверьте: не каждый сгенерированный экземпляр корректен, атрибуты можно добавлять и удалять.
3. **Из существующего атрибута.** Перетащите атрибут из TestSheet в папку и выберите **Create class from attribute** (в меню есть и **Create structure from attribute**). Класс получит податрибуты и экземпляры этого атрибута.

В остальном класс ничем не отличается от листа: у него свои атрибуты и экземпляры. В уроке Part 10 у класса есть ещё **экземпляры класса** (`Set 1`, `Set 2`), каждый из которых назначает атрибутам класса значения через панель деталей, чтобы лист мог выбрать сразу целый набор данных.

## Ссылка на класс из TestSheet

Перетащите класс на TestSheet. В листе появляется **ссылка на класс** с атрибутами и экземплярами класса. Повторите для каждого листа, которому нужны эти данные. Правила:

- Ссылка только для чтения: атрибуты и экземпляры внутри неё менять нельзя. Правьте класс — и каждая ссылка отразит изменение (удаление экземпляра в классе убирает его из всех ссылок).
- Правой кнопкой по ссылке **> Jump to referenced class** открывает класс.
- Если у класса есть экземпляры класса, выберите в ссылке нужный набор (`Set 1` или `Set 2`); лист будет использовать значения этого набора.
- В шаблоне атрибуты ссылки на класс привязываются к значениям TestStep так же, как атрибуты листа ([Шаблоны и инстанцирование](/ToscaBase/ru/test-case-design/templates-and-instantiation/)).

## Разрешение ссылки

Когда одному листу нужны общие атрибуты плюс свои добавления (`Payload` и `Total weight` для грузовиков), щёлкните ссылку на класс правой кнопкой **> Resolve class reference**. Ссылка превращается в обычные атрибуты листа, которые можно расширять. Связь с классом для этого листа теряется: последующие изменения класса до него не доходят, и атрибуты снова сопровождаются локально.

:::caution
Разрешайте ссылку только тогда, когда лист действительно должен разойтись с классом. Если добавления — необязательные поля, подумайте о том, чтобы оставить ссылку и добавить дополнительные атрибуты рядом с ней, сохранив общую часть под центральным управлением.
:::

## Место классов в процессе

Классы относятся к тому же проходу проектирования, что и лист: найдите атрибуты, повторяющиеся между листами, вынесите их в класс, сошлитесь на него, затем продолжайте с экземплярами и шаблонами. [Разбор](/ToscaBase/ru/test-case-design/worked-example-end-to-end/) показывает всю последовательность на одном приложении.
