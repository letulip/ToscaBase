Reference material that does not belong to a single topic. Use it when you know what you are looking for, or when you want to know where to start.

- [Learning path](/ToscaBase/reference/learning-path/) — every doc in the knowledge base in a recommended reading order, grouped by the four mastery levels: Foundations, Building tests, Specialised and Enterprise.
- [Glossary](/ToscaBase/reference/glossary/) — short definitions of every Tosca term used in ToscaBase, each linked to the doc that explains it.

Cheat sheets for ActionModes, steering parameters and common error messages will be added here as the docs that back them are written.
