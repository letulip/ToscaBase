This section takes you from zero to a running TestCase. It starts with what Tricentis Tosca is and which components make up the suite, then walks through the license, the installer, the first workspace and a tour of Tosca Commander, and ends with a complete login TestCase built from a scanned Module. The last pages summarise what changed in Tosca 16 and show the agentic, plain-English route to a TestCase in Tosca Cloud.
