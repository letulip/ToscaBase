Tricentis Device Cloud (TDC) is Tricentis' own device farm: physical smartphones and tablets hosted in the cloud, on which Tosca and Testim TestCases run and on which a tester can also work by hand. It was released on 8 August 2023; the first source announces it, the second is a hands-on recorded a week later. Beyond the device list that every cloud farm offers, TDC records a **performance session** for every run and lets a **mobile AI engine** turn the telemetry into issue cards, which is what the speaker singles out against SauceLabs and BrowserStack. Connecting Tosca to it follows the cloud connection described in [Mobile automation](/ToscaBase/engines/mobile-automation/).

## What it is

- **Real devices**: Apple iPhone, Samsung Galaxy, Google Pixel, Oppo, Vivo, Huawei and more, across Android and iOS versions, brands, models and locations. A trial account exposes two devices (a Samsung and an Apple in the source), a paid account many more.
- **Two Tricentis tools**: Tosca (model-based) and Testim (SaaS) both execute on it, so mobile runs sit in the same flow as web, desktop, SAP, Salesforce and API tests.
- **Mobile AI engine**: machine learning over the object, image, text, video and audio data collected during a run, plus 130+ KPIs of network, device and audio-visual quality, to surface issues before end users do.

:::note
The first source is an announcement and carries the vendor's market figures (share of people with a smartphone, of e-commerce revenue from mobile, of users who drop a slow app). They are marketing context, not product facts, and are left out here.
:::

## Remote control

The **Remote control** section lists the devices of your account with brand, model, OS version and location. **Start** on a device opens a mirroring session in the browser:

- interact with the phone directly: open Chrome, type a URL, scroll, return to the home screen;
- read the device details below the screen: serial number, carrier and network, model, OS version (Android 13 in the source), battery, CPU and memory; the location can be simulated;
- **Tools**: an ADB shell to send ADB commands to the device;
- **Apps**: choose an APK file from your computer to install it on the device;
- exploratory testing: **Start recording** (optionally with network capture) records the screen while you work; **Screenshot** captures the current state, for example an unexpected message after a login attempt.

**Stop** ends the session and frees the device.

## Performance sessions

Every interaction with a device, whether a Tosca run, a Testim run or a manual mirroring session, produces a performance session; the source's three-minute manual session shows up as one. Open it for:

- a **waterfall** view with the screen recording of the run;
- **time series** of every recorded metric, grouped as session-wide, domain, host and burst metrics: page content, frame rate, screen changes, concurrency, download speed, HTTP throughput, network bytes, CPU utilisation (including single-thread), memory used, input latency, frame render time, and the visual quality measures blurriness, blockiness, contrast and brightness;
- **issue cards** generated by the mobile AI engine from that telemetry, each with an impact score and a "what can I do" explanation. The source shows *slow server* (the first byte of HTTPS responses took over 500 ms), *slow downloads* (responses over 500 ms), *unoptimized resource* (a resource downloaded as uncompressed plain text), *long loading animations* and *low frame rate*.

The cards are meant to go straight to the developer: fix, redeploy to the device, rerun, compare.

## Performance monitoring

**Add to user flow** on a session groups sessions into a named **user flow** (`Chrome YouTube` in the source). The **Performance monitoring** section then tracks the user-experience and performance KPIs of that flow over time, so an improvement in a new build is visible against earlier runs. Two sessions can be compared against each other, with a device and a location chosen for the comparison, for example the same app accessed from the US and from India.
