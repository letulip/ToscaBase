This section closes the loop between business requirements and test results. It covers the Requirements section as a risk-weighted dashboard, the query language that selects objects for analysis, the reporting options that turn results into documents, and a shortcut for importing folder structures from Excel.

Read in this order:

1. [Requirements and risk weighting](/ToscaBase/requirements-and-reporting/requirements-and-risk/): structure requirements into folders, requirement sets and requirements; weight them directly or through frequency and damage class; link TestCases and ExecutionLists to get coverage and execution state.
2. [TQL search and virtual folders](/ToscaBase/requirements-and-reporting/tql-and-virtual-folders/): Tosca Query Language operators and structure, and virtual folders that store a query as a reusable view.
3. [Reports and report definitions](/ToscaBase/requirements-and-reporting/reports/): Print View, the default report definitions for ExecutionLists, TestCases and requirements, and how to build a custom report definition with a data set, a TQL query and a designer.
4. [Import a folder structure from Excel](/ToscaBase/requirements-and-reporting/import-from-excel/): paste a hierarchical worksheet into Commander with Create Folder Structure.
